Take over {{ node.name }}

LiteBlox imports this node's BIND config into its own settings, then writes the whole config itself from then on: /etc/bind/named.conf and the files in /etc/bind/liteblox/. It goes ahead only when named-checkconf -px of the generated config matches the node's own. The node is backed up first, its own config files move to /etc/bind/pre-liteblox/, and zone files are copied into /etc/bind/liteblox/. If a zone stops serving the same serial afterwards, the old config comes back automatically.
